      <h3>What is Parquet?</h3>
      <p>Apache Parquet is a popular columnar storage format known for:</p>
      <ul><li>reduced memory requirement,</li><li>fast data retrieval and filtering,</li><li>efficient storage.</li></ul>
      <p><b>This is what powers the dataset viewer</b> on each dataset page and every dataset on the Hub can be accessed with the same code (you can use HF Datasets, ClickHouse, DuckDB, Pandas, PostgreSQL, or Polars, <u>up to you</u>).</p>
      <p>You can learn more about the advantages associated with Parquet in the <u>documentation</u>.</p>
      <h3>How to access the Parquet version of the dataset?</h3>
      <p>You can access the Parquet version of the dataset by following this link: &nbsp;<a href="#" class="btn">refs/convert/parquet</a></p>
      <h3>What if my dataset was already in Parquet?</h3>
      <p>When the dataset is already in Parquet format, the data are not converted and the files in <code>refs/convert/parquet</code> are links to the original files. This rule has an exception to ensure the dataset viewer API to stay fast: if the row group size of the original Parquet files is too big, new Parquet files are generated.</p>
      <h3>What should I do?</h3>
      <p>You don't need to do anything. The Parquet version of the dataset is available for you to use. Refer to the <u>documentation</u> for examples and code snippets on how to query the Parquet files with ClickHouse, DuckDB, Pandas or Polars.</p>
