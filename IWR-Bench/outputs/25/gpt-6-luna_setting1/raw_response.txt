        <h2>Intuition</h2>
        <p>The Two Sum problem asks us to find two numbers in an array that sum up to a given target value. We need to return the indices of these two numbers.</p>
        <h2>Approach</h2>
        <ol>
          <li>One brute force approach is to consider every pair of elements and check if their sum equals the target. This can be done using nested loops, where the outer loop iterates from the first element to the second-to-last element, and the inner loop iterates from the next element to the last element. However, this approach has a time complexity of O(n^2).</li>
          <li>A more efficient approach is to use a hash table (unordered_map in C++). We can iterate through the array once, and for each element, check if the target minus the current element exists in the hash table. If it does, we have found a valid pair of numbers. If not, we add the current element to the hash table.</li>
        </ol>
        <p><strong>Approach using a hash table:</strong></p>
        <ol>
          <li>Create an empty hash table to store elements and their indices.</li>
          <li>Iterate through the array from left to right.</li>
          <li>For each element nums[i], calculate the complement by subtracting it from the target: complement = target - nums[i].</li>
          <li>Check if the complement exists in the hash table. If it does, we have found a solution.</li>
          <li>If the complement does not exist in the hash table, add the current element nums[i] to the hash table with its index as the value.</li>
          <li>Repeat steps 3-5 until we find a solution or reach the end of the array.</li>
          <li>If no solution is found, return an empty array or an appropriate indicator.</li>
        </ol>
        <p>This approach has a time complexity of O(n) since hash table lookups take constant time on average. It allows us to solve the Two Sum problem efficiently by making just one pass through the array.</p>
        <h2>Code</h2>
        <h2>Solution 1: (Brute Force)</h2>
        <div class="code-card">
          <div class="code-tabs"><span>C++</span><span>Java</span><span>Python3</span><button class="copy btn" title="Copy code">▢</button></div>
          <pre class="codeblock">class Solution {
public:
    vector&lt;int&gt; twoSum(vector&lt;int&gt;&amp; nums, int target) {
        int n = nums.size();
        for (int i = 0; i &lt; n - 1; i++) {
            for (int j = i + 1; j &lt; n; j++) {
                if (nums[i] + nums[j] == target) {
                    return {i, j};
                }
            }
        }
        return {}; // No solution found
    }
};</pre>

        <h2>Solution 2: (Two-pass Hash Table)</h2>
        <div class="code-card"><div class="code-tabs"><span>C++</span><span>Java</span><span>Python3</span></div><pre class="codeblock">class Solution {
public:
    vector&lt;int&gt; twoSum(vector&lt;int&gt;&amp; nums, int target) {
        unordered_map&lt;int, int&gt; seen;
        for (int i = 0; i &lt; nums.size(); i++) {
            int complement = target - nums[i];
            if (seen.count(complement)) return {seen[complement], i};
            seen[nums[i]] = i;
        }
        return {};
    }
};</pre></div>
